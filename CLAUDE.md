# aap-runner: rules for every agent working in this repo

- Commits are authored and committed as `special-place-administrator <197073597+special-place-administrator@users.noreply.github.com>` only. No `Co-Authored-By`, no `Claude-Session` trailers. Branch plus PR; never force-push `main`.
- This repo is PUBLIC and the org's self-hosted runners may be shared with it. Never use `pull_request_target` together with a checkout of the pull request's code, and never run untrusted PR code on `runs-on: {group: aap-crrr, ...}`. Hosted runners (`ubuntu-latest`, `windows-latest`) are the default for CI here; the self-hosted group is for jobs that must run on the real runner host and only on `push` to `main` or on PRs from branches in this repo.
- Three parts, three test suites, all must stay green: `distro/` (bash; `bash distro/manager.sh --self-check`, `bash distro/bootstrap.sh --self-check`, `bash tests/run.sh`, shellcheck 0.11 at `-S warning`), `supervisor/` (PowerShell; Pester 5 on Windows PowerShell 5.1 and pwsh 7), `crates/tray` (Rust; `cargo fmt --all --check`, `cargo clippy --all-targets --locked -- -D warnings`, `cargo test --locked`). The bash suite needs a real Linux (WSL Ubuntu); Git Bash lacks `setsid`/`flock`.
- Contracts between the parts are versioned files: `distro/README.md` (status.json, limits.conf), `supervisor/README.md` (Windows status.json, inbox state.json/settings.json), `crates/tray/README.md`. A change to one side updates the contract doc and the other sides' tests in the same PR.
- Secrets: the GitHub App private key lives only inside the distro (`/etc/aap-runner/app.pem`, root 0400). Nothing here ever prints, copies or logs it. No tokens in the tray; the tray never runs `wsl.exe`.
- The live install on the owner's machine is updated only on the owner's word; code changes land on `main` first.
